    Python API

    treehawk is a command-line tool first. The Python API documented here is what you build on when you extend it: the protocols the layers meet at, the settings, the error hierarchy, and the functions that read a log back.

    Not yet stable

    treehawk is at version 0.x. These interfaces may change between minor releases; pin the version you build against.

    Protocols

    Every component asks for the one capability it uses. Implementations satisfy these structurally: no inheritance is needed.

    The abstractions every other layer depends on.

    Kept deliberately narrow (Interface Segregation): a component asks for the one capability it uses, not for a god-object "backend". Concrete Linux/macOS/GPU implementations satisfy these structurally - no inheritance required.

    Record module-attribute 

    Record: TypeAlias = dict[str, object]

    One serialised log record. Deliberately loose: sinks must stay indifferent to which fields a schema version happens to carry, so a value is narrowed where it is read (see :mod:treehawk.core.values).

    ProcessSource

    Bases: Protocol

    Reads live process state from the OS.

    scan 

    scan() -> Mapping[int, ProcInfo]

    Return cheap facts for every visible process, one pass.

    read_info 

    read_info(pid: int) -> ProcInfo | None

    Return cheap facts for one process, or None if it is gone.

    read_cmdline 

    read_cmdline(pid: int) -> str

    Return the full command line, or "" if unreadable.

    read_group_path 

    read_group_path(pid: int) -> str | None

    Return the process' group boundary path (cgroup), if any.

    enrich 

    enrich(*, info: ProcInfo, memory: MemoryDetail) -> ProcSample

    Add the costlier fields (command line, PSS, swap, group) to info.

    forget 

    forget(identity: Identity) -> None

    Drop any cached state for a process that has exited.

    GroupMetricSource

    Bases: Protocol

    Reads kernel-side aggregates for a process group boundary (cgroup).

    pids_in 

    pids_in(path: str) -> set[int] | None

    PIDs in path and all of its descendants, or None if unreadable.

    ProcessLauncher

    Bases: Protocol

    Starts a workload, ideally inside its own accounting boundary.

    HostInfoSource

    Bases: Protocol

    ProcessMatcher

    Bases: Protocol

    Decides whether a process is the workload the user asked for.

    needs_cmdline property 

    needs_cmdline: bool

    True if :meth:matches inspects the command line.

    names_one_process property 

    names_one_process: bool

    True if the matcher names a single process outright.

    The exclusions that stop a keyword from matching the shell you typed it in do not apply to a matcher this specific - you meant that process.

    describe 

    describe() -> Record

    Serializable description, recorded in the log header.

    ExpansionStrategy

    Bases: Protocol

    Finds processes that belong to the workload but were not matched directly.

    One rule per implementation; the tracker applies whichever set it is given, so new rules never require editing the tracker (Open/Closed).

    expand 

    expand(context: ExpansionContext) -> Mapping[int, str]

    Return {pid: reason} for processes to adopt into the workload.

    ExpansionContext 

    ExpansionContext(*, procs: Mapping[int, ProcInfo], tracked_pids: set[int], new_pids: set[int], children: Mapping[int, list[int]], source: ProcessSource, groups: GroupMetricSource | None, self_pid: int, self_group: str | None, self_sid: int, pinned_group: str | None)

    Everything an :class:ExpansionStrategy may look at.

    Passing a context object (rather than a growing argument list) lets new strategies use new inputs without changing the strategy interface.

    group_of 

    group_of(pid: int) -> str | None

    Group path of pid, memoized for the duration of this sample.

    MetricCollector

    Bases: Protocol

    Contributes extra metrics to each sample (GPU, I/O, ... ).

    Collectors are additive: the monitor merges whatever they return into the sample record under the collector's namespace, so adding one changes no existing code path.

    Sink

    Bases: Protocol

    Writes records somewhere. Every sink is substitutable for any other.

    Clock

    Bases: Protocol

    Time and sleeping, injected so the sampling loop is testable.

    Settings

    User-facing run settings, in one place.

    Every choice that changes what the program does is a named value rather than a flag, so a call site says which behaviour it wants instead of leaving the reader to work out what True meant.

    ExpansionName

    Bases: StrEnum

    Membership rules, by name. The CLI renders these as its choices.

    LogDetail

    Bases: StrEnum

    How much of each sample is written out.

    AGGREGATE class-attribute instance-attribute 

    AGGREGATE = 'aggregate'

    The workload total only - much smaller logs for a run that lasts days.

    PER_PROCESS class-attribute instance-attribute 

    PER_PROCESS = 'per-process'

    The total plus one row per process.

    MemoryDetail

    Bases: StrEnum

    Which memory measurement is worth paying for.

    RESIDENT class-attribute instance-attribute 

    RESIDENT = 'resident'

    RSS only. Cheap, but summing it over-counts pages shared by children.

    PROPORTIONAL class-attribute instance-attribute 

    PROPORTIONAL = 'proportional'

    Also read PSS, which divides a shared page between its users.

    MissingWorkload

    Bases: StrEnum

    What to do when nothing matches at startup.

    WhenEmpty

    Bases: StrEnum

    What to do when a sample finds no processes left alive.

    CpuSource

    Bases: StrEnum

    Which CPU counter the workload total is derived from.

    PROCESSES class-attribute instance-attribute 

    PROCESSES = 'processes'

    Summed per-process counters, plus the members that have since exited.

    GROUP class-attribute instance-attribute 

    GROUP = 'group'

    The kernel's own cgroup counter - it also covers processes that were born and died between two samples.

    Isolation

    Bases: StrEnum

    Whether a launched workload gets an accounting boundary of its own.

    LogFormat

    Bases: StrEnum

    On-disk formats the log can be written in.

    WatchConfig dataclass 

    WatchConfig(interval: float = 1.0, duration: float | None = None, max_samples: int | None = None, detail: LogDetail = PER_PROCESS, memory: MemoryDetail = PROPORTIONAL, expand: tuple[ExpansionName, ...] = (lambda: DEFAULT_EXPANSIONS)(), missing_workload: MissingWorkload = FAIL, when_empty: WhenEmpty = STOP, top_n: int = 5, collectors: tuple[str, ...] = ())

    Everything the monitor needs to know about how to watch.

    Models

    Value objects shared across the application.

    Plain data carriers with no behaviour beyond trivial derivations, so that every other component can depend on them without depending on each other.

    ProcInfo dataclass 

    ProcInfo(pid: int, ppid: int, pgid: int, sid: int, starttime: int, state: str, threads: int, comm: str, cpu_ticks: int, rss_bytes: int | None)

    Cheap per-process facts, available from a single stat read.

    ProcSample dataclass 

    ProcSample(info: ProcInfo, cmdline: str = '', pss_bytes: int | None = None, swap_bytes: int | None = None, cgroup: str | None = None, via: str = 'seed', cpu_percent: float | None = None)

    A tracked process at one instant: cheap facts plus enriched fields.

    GroupMetrics dataclass 

    GroupMetrics(path: str, cpu_usec: int | None = None, memory_bytes: int | None = None, memory_peak_bytes: int | None = None)

    Kernel-side aggregates for a process group boundary (a cgroup).

    Snapshot dataclass 

    Snapshot(seq: int, t: float, timestamp: str, procs: list[ProcSample] = list(), cpu_percent: float | None = None, cpu_percent_norm: float | None = None, cpu_seconds_total: float = 0.0, cpu_seconds_used: float = 0.0, rss_bytes: int | None = None, pss_bytes: int | None = None, swap_bytes: int | None = None, group: GroupMetrics | None = None, overrun: bool = False, extra: dict[str, Mapping[str, object]] = dict())

    One fully computed sample: the aggregate plus its per-process detail.

    HostInfo dataclass 

    HostInfo(platform: str, hostname: str, ncpu: int, clk_tck: int, page_size: int, mem_total_bytes: int | None)

    Facts about the machine, read once at startup.

    LaunchedWorkload 

    LaunchedWorkload(*, pid: int, argv: list[str], group_path: str | None = None)

    Bases: ABC

    A process treehawk started, and the two things it needs to do to it.

    An abstract class rather than a bag of callables: it keeps the signalling and reaping rules with the implementation that knows how the process was started, and it is substitutable - the CLI treats a systemd scope and a bare subprocess identically.

    isolated property 

    isolated: bool

    True when the workload has an accounting boundary of its own.

    Derived rather than declared: owning a cgroup path is what being isolated means, so the two cannot drift apart.

    poll abstractmethod 

    poll() -> int | None

    Exit code if the workload has finished, else None. Never blocks.

    signal abstractmethod 

    signal(signum: int = SIGTERM) -> None

    Forward a signal to the workload, ignoring a process already gone.

    Errors

    Every failure treehawk decides to stop for.

    One hierarchy, so the command line can handle all of them in one place instead of knowing which module raises what. Submodules raise; only the CLI catches.

    Exit codes live on the class rather than at the catch site, because the code a failure deserves is a property of the failure, not of who noticed it.

    TreehawkError

    Bases: RuntimeError

    Base of every deliberate failure. Anything else is a bug.

    ConfigError

    Bases: TreehawkError, ValueError

    The run was described in a way treehawk cannot carry out.

    Also a ValueError: it is what a caller outside the CLI would expect from WatchConfig.validate() or a factory handed an unknown name.

    UnsupportedPlatform

    Bases: TreehawkError

    treehawk has no implementation for this operating system yet.

    WorkloadNotFound

    Bases: TreehawkError

    Nothing matched the user's request (within --wait, if given).

    LaunchFailed

    Bases: TreehawkError

    The workload could not be started.

    ReportError

    Bases: TreehawkError

    A log could not be read, or contained no samples.

    Reading logs

    Reading a treehawk log back.

    Produces the figures people ask for - peak and mean CPU, peak memory, total CPU time, and which process was responsible - as plain data. Rendering belongs to :mod:treehawk.ui.views (terminal) and :mod:treehawk.charts (PDF), so one reader serves both.

    Uses the recorded summary when the run finished cleanly and recomputes from the samples when it did not, so an interrupted or killed run still reports.

    Report

    Bases: TypedDict

    A log, read back: the run's metadata and its computed figures.

    build_report 

    build_report(path: str, *, top_n: int = 5) -> Report

    read_records 

    read_records(path: str) -> Iterator[Record]

    write_pdf_report 

    write_pdf_report(*, log_path: str, destination: str, pages: Sequence[Page] = PAGES, palette: Palette = PRINT) -> int

    Render log_path as a PDF. Returns the number of pages written.

    Narrowing log values

    Reading values back out of records.

    A record is a plain dictionary that has usually been through JSON, where any field may legitimately be null and nothing guarantees a number is a number. These coercions are the one place that fact is dealt with, so every renderer does not grow its own private copy.

    as_float 

    as_float(value: object) -> float | None

    The value as a float, or None if it is not a number.

    as_int 

    as_int(value: object) -> int | None

    The value as an int, or None if it is not a number.

    as_mapping 

    as_mapping(value: object) -> Mapping[str, object]

    The value as a record-like mapping, or an empty one if it is not.

    as_records 

    as_records(value: object) -> list[dict[str, object]]

    The value as a list of records, skipping anything that is not one.

    as_sequence 

    as_sequence(value: object) -> Sequence[object]

    The value as a sequence, or an empty one if it is not a list or tuple.

    peak_of 

    peak_of(*, current: T | None, candidate: T | None) -> T | None

    The larger of the two, where None means "nothing measured yet".
